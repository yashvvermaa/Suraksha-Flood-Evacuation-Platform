📌 About the Project

Suraksha is a flood evacuation platform designed for Bihar. It helps people navigate flood emergencies by providing flood alerts, nearby open shelters with available capacity, and safer routes that avoid flooded roads.

The platform aims to help people identify suitable shelters and reach them more efficiently during flood situations.

**Demo Location:** Darbhanga, Bihar  
**Data:** Sample/Demo Data

 ✨ Key Features

- **Flood Alerts:** Displays flood-related alerts.
- **Nearby Shelters:** Helps locate nearby open evacuation shelters.
- **Shelter Capacity:** Shows available capacity at shelters.
- **Safe Routes:** Suggests routes that avoid flooded roads.

 🎯 Problem Statement

Flooding creates serious challenges for evacuation, especially when people struggle to find accessible shelters and safe routes.

Suraksha explores how technology can make evacuation information easier to access through a single platform.
